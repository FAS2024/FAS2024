## How I work

* Prefer small, clear changes that are easy to review
* Keep API and business logic organized and easy to maintain
* Separate background jobs from request/response processing when needed
* Use caching when it solves a real performance problem
* Pay attention to database queries, indexes, and application performance
* Write tests for important application behavior
* Try to make projects easy to run with clear documentation and environment configuration
* Use Docker to keep development and deployment environments consistent
* Use CI/CD to automate testing and deployment
* Treat authentication and authorization as part of the system design
* Debug issues from logs, tests, database behavior, and application metrics rather than guessing
